DigiKey is a global distributor of electronic components. Its developer portal (developer.digikey.com) publishes OAuth 2.0 REST APIs on api.digikey.com for product search, pricing and inventory (Product Information V4), product change notifications, quoting, ordering, order status and order management, MyLists, supply chain (consigned inventory locations), barcode decoding and packing lists, with a sandbox at sandbox-api.digikey.com.

**Areas:** Shopping · Public APIs · Electronic Components · Distribution · Ordering · Product Search · Pricing · Inventory · Supply Chain

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Digi-Key: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
